# Universal product rename request

The owner requested that the product and public repository stop using a computer-shop-specific product name so the same system can be used by other repair businesses.

Confirmed direction:

- Use a universal product name instead of an industry-specific name.
- Keep the existing repair, service, inventory, customer, sales, and reporting capabilities.
- Rename the repository and installer-facing artifacts.
- Preserve installed data and upgrade compatibility during the rename.

Chosen product name: **Universal Repair POS**.
