# Standalone installer, backup, restore, update, and owner setup request

Source: user requests received 2026-09-28.

- Produce standalone installers for Windows 64-bit and Linux without requiring Docker.
- Optimize the Linux edition for a low-spec Celeron computer with 4 GB RAM.
- Store durable application data under the user's Documents folder by default.
- Create automatic daily backups in a separate backup folder.
- Provide manual backup and restore controls.
- Preserve all data when installing newer versions.
- Add a Check for Updates control for future releases.
- Begin with localhost use and offer a guided same-Wi-Fi/LAN access choice.
- Extend first-run setup to collect the owner's name, username, email if desired, and a custom password.
- Make a fresh installation unusable through default administrator credentials before owner setup is completed.
