# Conditional catalog fields and manual client management request

Source: owner requests supplied in Codex on 2026-09-28. The catalog-form screenshot is preserved as `2026-09-28-catalog-type-stock-reference.png`.

## Catalog form

- Hide estimated service duration when Catalog Type is Physical Product.
- Show estimated service duration when Catalog Type is Service / Repair.
- Keep Actual Cost and Selling Price visible for both types because repair work can consume materials such as thermal paste.
- For physical products, add a quantity field for the number of units currently owned/in stock.

## Clients

- Allow clients to be added manually without first creating a sale.
- Allow saved client details, including the contact/WhatsApp number, to be edited.
- Support optional client details such as a photo.
