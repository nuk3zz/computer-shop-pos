# Supplier generated reference request

Source: owner feature request received 2026-09-29.

- Add a simple, lightweight built-in PDF document for supplier ledger transactions.
- When a supplier invoice or screenshot was uploaded, retain it as the original evidence.
- When no file was uploaded, Supply Chain transaction history should offer a generated reference through a small View action.
- The first version may be visually simple; a richer invoice designer is deferred.
- Publish the feature as v0.3.5 so the built-in updater in v0.3.4 can be tested.
