# Public documentation privacy

Source: [`raw/2026-09-28-public-documentation-privacy-request.md`](../raw/2026-09-28-public-documentation-privacy-request.md)

- Treat this repository as public.
- Never publish personal device names, personal example usernames, absolute user paths, private addresses, credentials, or owner-specific network details.
- Use product-neutral labels such as `server`, `host computer`, `owner`, `<server-ip>`, and `local network`.
- Hardware or operating-system names may appear only when they are genuinely required for product installation or compatibility instructions, never merely because they describe the owner's current machine.
- Before committing documentation, search the tracked tree for personal identifiers and machine-specific details.
